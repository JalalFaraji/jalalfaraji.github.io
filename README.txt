JALAL FARAJI — FREE ACADEMIC PROFILE

This is a free, static one-page website made with HTML and CSS.

PUBLISH WITH GITHUB PAGES
1. Sign in to https://github.com/JalalFaraji
2. Create a NEW PUBLIC repository named exactly:
   jalalfaraji.github.io
3. Upload index.html and jalal_faraji_contact.vcf to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. The site should publish at https://jalalfaraji.github.io/

IMPORTANT
- All page text is in English.
- This page displays the contact details provided by Jalal.
- The website is public. Anyone with its URL can view the contact details.
- Once published, generate a NEW QR code pointing to https://jalalfaraji.github.io/
  The old vCard QR points directly to contact data, not to this website.
